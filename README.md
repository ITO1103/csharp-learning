# csharp-learning
C#の基礎から，クラス設計，オブジェクト指向，データ構造，アルゴリズムまで継続的に学習するためのリポジトリ．

複数クラスを用いた設計や依存関係の扱いについて理解を深めることを目的としています．

## 使い方
1. `docker-compose up -d` を実行してコンテナを起動．
2. コンテナ内に移動．
3. `dotnet new console` を実行して新しいコンソールアプリケーションを作成．
4. `dotnet run` を実行してコードを実行．
5. `docker-compose down` を実行してコンテナを停止．

## 目的
- C#の基本文法の理解
- クラス，オブジェクト，インスタンスの関係を理解
- 複数クラスを用いたプログラムの設計，実装
- データ構造の理解
- 再帰，DFS，BFSなどのアルゴリズムの理解，実装
- 依存関係グラフや逆依存関係の理解，実装
- 複数クラスやファイルで構成される大規模プログラムの設計，実装
