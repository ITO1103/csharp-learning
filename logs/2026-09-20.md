## 学んだこと

### List<T>

`List<T>`では，`Add()`，`Remove()`，`Count`，`IndexOf()`，`Sort()`などを利用して要素を操作できる．

フィボナッチ数列の例では，

```csharp
var previous = fibonacciNumbers[fibonacciNumbers.Count - 1];
var previous2 = fibonacciNumbers[fibonacciNumbers.Count - 2];
```

のように，末尾や末尾から2番目の要素を取得できることを確認した．

### IEnumerable<T>とyield return

`IEnumerable<T>`は，複数の値を順番に列挙できるものを表す．
そのため，`IEnumerable<T>`を返すメソッドは`foreach`で処理できる．

```csharp
static IEnumerable<(TransactionType type, double amount)> TransactionRecords(...)
```

`yield return`を使用すると，値を1個返したところで一旦処理を止め，次の値が要求されたときに続きから処理を再開できる．

```csharp
yield return (TransactionType.Deposit, amount);
```

最初は「複数の値を同時に返している」と考えていたが，実際には1個ずつ順番に返している．

### enumと名前付きタプル

`enum`を使用すると，取り得る値を限定した独自の型を定義できる．

```csharp
public enum TransactionType
{
    Deposit,
    Withdrawal,
    Invalid
}
```

また，

```csharp
(TransactionType type, double amount)
```

の`type`と`amount`はタプルの要素名であり，

```csharp
transaction.type
transaction.amount
```

のようにアクセスできる．

### switch式とパターンマッチング

switch文は処理を分岐するが，switch式では条件に応じた値を直接返すことができる．

```csharp
currentBalance += transaction switch
{
    (TransactionType.Deposit, var amount) => amount,
    (TransactionType.Withdrawal, var amount) => -amount,
    _ => 0.0,
};
```

この例では，タプルの内容を見て値を返している．

また，型パターンを使用すると，オブジェクトの実際の型を見て分岐できる．

```csharp
currentBalance += transaction switch
{
    Deposit d => d.Amount,
    Withdrawal w => -w.Amount,
    _ => 0.0,
};
```

`Deposit d`は，対象が`Deposit`型の場合にそのオブジェクトを`d`として扱うという意味であり，`d.Amount`は通常のオブジェクトのプロパティアクセスと同じである．

### record

`record`は，データのまとまりを表現することに向いた参照型である．

```csharp
public record Deposit(double Amount, string Description);
```

普通のclassでは，別々に生成したオブジェクトは中身が同じでも，デフォルトでは`==`による比較はfalseになる．
一方，recordでは値に基づいた比較が最初から利用できる．

また，recordは参照型なので，

```csharp
var b = a;
```

とすると，aとbは同じオブジェクトを参照する．

一方，record structは値型なので，代入時に値そのものがコピーされる．

recordは必ず変更不可というわけではないが，位置指定recordは変更しないデータとして扱いやすく，`with`を使用して一部だけ変えた新しいオブジェクトを作ることもできる．

### 参照型と値型

参照型では，代入時にオブジェクトそのものではなく参照がコピーされる．

一方，値型では値そのものがコピーされる．

大まかには，

- class / record：参照型
- struct / record struct：値型

である．

### nullable参照型

```csharp
string? line;
```

の`?`は，その変数が`null`になる可能性があることを示す．

また，

```csharp
transactionType?.ToUpper()
```

の`?.`は，`transactionType`が`null`でない場合のみ`ToUpper()`を実行する．

### プログラムの構造

最上位レベルのステートメントを使用すると，明示的な`Main`メソッドを書かずに処理を記述できる．

```csharp
Console.WriteLine("Hello, World!");
```

一方，従来の形式では，

```csharp
class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello, World!");
    }
}
```

のように`Main`メソッドを定義する．

また，.NET 10のファイルベースアプリでは`.csproj`を用意せずにC#ファイルを直接実行できる．

```bash
dotnet FilebaseApp.cs
```

ファイルの先頭に，

```bash
#!/usr/bin/env dotnet
```

を記述し，実行権限を付けることで，

```bash
./FilebaseApp.cs
```

のように実行できることも確認した．

### C#のコンパイルとJIT

C#は，

```text
C#ソースコード
↓
IL
↓
JITコンパイル
↓
機械語
```

という流れで実行される．

JITは実行時に必要なコードをCPU向けの機械語へ変換する仕組みである．

AppleのRosetta2も実行環境向けにコードを変換する点では似ている．
