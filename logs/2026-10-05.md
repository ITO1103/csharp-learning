## 学んだこと

### 式の評価

演算子には優先順位があり，`/`は`+`より先に評価される．

```csharp
int result = 3 + 6 / 2;
```

また，括弧を使うことで評価するまとまりを明示できる．

```csharp
bool access2 = isAdmin && (isOwner || true);
```

`&&`と`||`では，結果が確定した場合に右側を評価しない短絡評価が行われる．

```csharp
bool hasContent = text != null && text.Length > 0;
```

### 等価比較

通常の`class`は既定では参照の等価性を使うため，内容が同じでも別々に`new`したインスタンスは等しくならない．

```csharp
var order1 = new Order(42, "Shoes");
var order2 = new Order(42, "Shoes");

Console.WriteLine(order1 == order2);
```

`ReferenceEquals`を使うと，2つの変数が同じインスタンスを参照しているか直接確認できる．

```csharp
Console.WriteLine(ReferenceEquals(doc1, doc3));
```

一方，`record`では値の等価性が自動的に実装されるため，別々のインスタンスでもプロパティの値が同じなら等しい．

```csharp
var person1 = new Person("Ada", "Lovelace");
var person2 = new Person("Ada", "Lovelace");

Console.WriteLine(person1 == person2);
```

ただし，`record`のメンバーに`List<T>`などの参照型が含まれている場合，そのメンバー自身の等価性が使われる．

```csharp
Console.WriteLine(playlist1.Equals(playlist2));
Console.WriteLine(playlist1.Tracks.SequenceEqual(playlist2.Tracks));
```

### 演算子

整数同士の除算では小数部が0に近づく方向に切り捨てられる．

```csharp
int result = 7 / 2;
int negResult = -7 / 2;
```

前置`++`は値を増やしてから使用し，後置`++`は現在の値を使用してから増やす．

```csharp
int a = ++counter;
int b = counter++;
```

条件演算子`?:`では，条件に応じてどちらか一方の式だけが評価される．

```csharp
int safe = divisor == 0 ? -1 : 10 / divisor;
```

複合代入演算子では，演算と代入をまとめて記述できる．

```csharp
hp += 20;
hp -= 10;
hp *= 2;
hp /= 3;
hp %= 7;
```

また，代入は右結合なので右側から順に評価される．

```csharp
a2 = b2 = c2 = 0;
```

## 詰まったこと・分からなかったこと・知らなかったこと

- `&&`は`||`より優先順位が高いこと
- 短絡評価では結果が確定した時点で右側の式が評価されないこと
- 通常の`class`では既定で参照の等価性が使われること
- `record class`は参照型だが，`==`や`Equals`では値を比較すること
- `record`内に参照型のメンバーがある場合，その型自身の等価性が使用されること
- 整数除算では負の値でも0に近づく方向に切り捨てられること
- `%`の結果の符号は左側の値に従うこと
- 前置と後置の`++`，`--`では式として使用した場合の値が異なること
- C#には`===`演算子がないこと
- 複合代入では計算結果が左辺の型に変換されること
- 代入演算子は右結合であること
