## 学んだこと

### class

classでは，コンストラクタを使ってオブジェクト生成時に値を受け取り，プロパティやフィールドへ設定できる．

```csharp
public class Customer
{
    public string Name { get; set; }

    public Customer(string name)
    {
        Name = name;
    }
}
```

```csharp
var customer = new Customer("Alice");
```

とすると，`"Alice"`がコンストラクタの`name`に渡され，`Name`プロパティへ代入される．

コンストラクタはクラス名と同じ名前で定義し，戻り値の型は書かない．

また，オブジェクト初期化子を使うと，呼び出し側からプロパティへ値を設定できる．

```csharp
var options = new ConnectionOptions
{
    Host = "db.example.com",
    Port = 5432,
    UseSsl = true
};
```

コンストラクタがオブジェクト生成時の初期化処理を定義するのに対し，オブジェクト初期化子では`new`した際に呼び出し側から各プロパティを設定する．

### フィールドとプロパティ

classやstructの中に定義されているフィールド，プロパティ，メソッドなどをまとめてメンバーと呼ぶ．

フィールドは値を保持する変数で，

```csharp
private int _capacity;
```

のようにprivateフィールドでは先頭に`_`を付ける命名規則がよく使われる．

プロパティでは，

```csharp
public string Name { get; set; }
```

のように`get`と`set`によって値の取得や変更を制御できる．

C#では，publicなプロパティやメソッドにはPascalCase，引数やローカル変数にはcamelCaseを使用するのが一般的．

### static class

`static class`はインスタンス化できず，staticメンバーのみを持つ．

```csharp
static class MathHelpers
{
    public static double CircleCircumference(double radius)
        => 2 * Math.PI * radius;
}
```

使用するときは，

```csharp
double circumference = MathHelpers.CircleCircumference(5.0);
```

のように`new`せず，型名から直接呼び出す．

### struct

structは値型なので，代入すると参照ではなく値そのものがコピーされる．

```csharp
var p1 = new Point { X = 3, Y = 4 };
var p2 = p1;

p2.X = 10;
```

この場合，`p2`を変更しても`p1`には影響しない．

structにもコンストラクタやメソッドを定義できる．

```csharp
public readonly double DistanceTo(Point other)
{
    var dx = X - other.X;
    var dy = Y - other.Y;
    return Math.Sqrt(dx * dx + dy * dy);
}
```

`Point other`は，`Point`型の値を`other`という引数名で受け取るという意味．

### readonly structとreadonlyメンバー

```csharp
readonly struct Temperature
```

のようにすると，構造体全体を読み取り専用にでき，作成後に状態を変更できない．

```csharp
readonly struct Temperature
{
    public double Celsius { get; }

    public Temperature(double celsius)
        => Celsius = celsius;
}
```

一方，通常のstructでも，

```csharp
public readonly double Speed => Math.Sqrt(X * X + Y * Y);
```

のように，特定のメンバーだけを`readonly`にできる．

`readonly struct`は構造体全体，`readonly`メンバーはそのメンバー内で構造体の状態を変更しないことを表す．

### record

`record`はデータを表す用途に向いており，別インスタンスでも保持している値が同じであれば等しいものとして比較できる．

```csharp
public record Person(string FirstName, string LastName);
```

```csharp
var p1 = new Person("Grace", "Hopper");
var p2 = new Person("Grace", "Hopper");

Console.WriteLine(p1 == p2); // true
```

`record`は既定では`record class`であり，参照型となる．

一方，

```csharp
public record struct Coordinate(double Latitude, double Longitude);
```

のようにすると値型となる．

また，位置指定recordで生成されるプロパティは基本的にinit専用となり，初期化後は通常の`set`のように変更できない．

### recordの値の等価性と参照型

recordの値比較では，各プロパティの等価性が使われるが，配列などの参照型の中身まで自動的に深く比較されるわけではない．

```csharp
var phones = new string[] { "555-1234" };

var person1 = new Person("Grace", "Hopper", phones);
var person2 = new Person("Grace", "Hopper", phones);
```

この場合，`person1`と`person2`は同じ`phones`配列を参照している．

そのため，

```csharp
person1.PhoneNumbers[0] = "555-9999";
```

とすると，

```csharp
Console.WriteLine(person2.PhoneNumbers[0]);
```

でも変更後の値が表示される．

### with式

recordでは`with`式によって，元のrecordを変更せず，一部の値だけ変更した新しいrecordを作成できる．

```csharp
var original = new Person("Grace", "Hopper");
var modified = original with { FirstName = "Margaret" };
```

`original`自体は変更されない．

### デコンストラクション

位置指定recordでは，定義した順番でプロパティの値を取り出すことができる．

```csharp
public record Person(string FirstName, string LastName);

var person = new Person("Grace", "Hopper");

var (first, last) = person;
```

この場合，

```text
first = "Grace"
last  = "Hopper"
```

となる．

### recordの継承

recordも別のrecordを継承できる．

```csharp
public record Person(string FirstName, string LastName);

public record Student(
    string FirstName,
    string LastName,
    int GradeLevel
) : Person(FirstName, LastName);
```

この場合，`Student`は`Person`の一種として扱うことができる．

```csharp
var p1 = new Student("BOB", "BabyOnBoard", 1);

Person person = p1;
```

`person`のコンパイル時の型は`Person`なので，

```csharp
person.GradeLevel
```

にはアクセスできない．

一方，実行時の実体は`Student`のままなので，

```csharp
Console.WriteLine(person);
```

では実体である`Student`の`ToString()`が呼ばれ，`GradeLevel`も表示される．

以前学習した「コンパイル時の型」と「実行時の型」の違いが，recordの継承でも確認できた．
