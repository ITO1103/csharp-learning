## 学んだこと

### ステートメント

ステートメントは処理を実行する単位．代入式，メソッド呼び出し式，インクリメント式などをステートメントとして書ける．

```csharp
int quantity = 5;

quantity = 10;
Console.WriteLine("Restocking");
quantity++;
```

ブロックの中で宣言した変数は，そのブロックの中でだけ使用できる．

```csharp
int outerValue = 10;

if (outerValue > 0)
{
    int innerValue = outerValue * 2;
}
```

### 選択ステートメント

`if`や`else if`では条件に応じて処理を分岐できる．`switch`では値やパターンを確認して，実行する処理を選択できる．

`case`に比較パターンを指定したり，`when`で条件を追加したりできる．

```csharp
int measurement = 42;

switch (measurement)
{
    case < 0:
        Console.WriteLine("Negative");
        break;
    case 0:
        Console.WriteLine("Zero");
        break;
    case > 0 when measurement % 2 == 0:
        Console.WriteLine("Positive and even");
        break;
    default:
        Console.WriteLine("Positive and odd");
        break;
}
```

### コレクション

配列は作成した後に要素数を変更できないが，要素の値は変更できる．`List<T>`では要素の追加や削除ができる．

```csharp
string[] stages = ["design", "code", "test"];
stages[0] = "plan";

List<string> workItems = ["design", "code", "test"];
workItems.Add("review");
workItems.Remove("code");
```

`Dictionary<TKey, TValue>`では，キーを使って値を取得できる．コレクション式では`..`を使って別のコレクションの要素を展開できる．インデックスと範囲を使うと，位置や範囲を指定して要素を取得できる．

### LINQ

LINQのメソッド構文では，`Where`で条件に合う要素を選び，`OrderBy`で並べ替え，`Select`で必要な値を取り出せる．

```csharp
IEnumerable<string> query = names
    .Where(name => name.Length >= 4)
    .OrderBy(name => name)
    .Select(name => name);
```

クエリ式構文では，`from`，`where`，`orderby`，`select`などを使って同じような処理を書ける．`let`を使うと，クエリの途中の値に名前を付けられる．

`GroupBy`を使うと，指定したキーが同じ要素をグループにまとめられる．複数のクエリを組み合わせて，条件を段階的に追加することもできる．

クエリは列挙されるときに実行される．`Count()`や`ToList()`のように結果をすぐに返すメソッドは，呼び出した時点で実行される．

## 詰まったこと・分からなかったこと・知らなかったこと

- ステートメントの中に式が含まれていること
- ブロックの中で宣言した変数をブロックの外から使えないこと
- `switch`の`case`に比較パターンや`when`を指定できること
- 配列は要素数を変更できず，`List<T>`は要素を追加・削除できること
- コレクション式の`..`で別のコレクションの要素を展開できること
- LINQにメソッド構文とクエリ式構文があること
- LINQのクエリは列挙時に実行され，`Count()`は呼び出した時点で実行されること
- コレクションのページが英語版だったこと
