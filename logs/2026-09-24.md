## 学んだこと

### 型変換

数値型では，変換しても情報が失われない場合は暗黙的な型変換ができる．

```csharp
int itemCount = 42;
long widened = itemCount;
```

一方，`double`から`int`のように情報が失われる可能性がある場合は，明示的な型変換を行う．

```csharp
double average = 19.75;
int truncated = (int)average;
```

この場合，小数部分が失われて`19`になる．

参照型では，継承関係やinterfaceの実装関係によって別の型として扱うことができる．

```csharp
Mammal otter = new() { Name = "River Otter" };

Animal animal = otter;
INamed named = otter;
object obj = otter;
```

`Mammal`は`Animal`を継承しているため`Animal`として扱うことができ，`INamed`を実装していれば`INamed`としても扱える．

`is`を使うと，実体が特定の型として扱えるか確認できる．

```csharp
if (knownAnimal is Mammal mammal)
{
    Console.WriteLine(mammal.Name);
}
```

`as`を使うと型変換を試し，変換できなかった場合は`null`になる．

```csharp
Mammal? maybeMammal = boxedMammal as Mammal;
```

### ボックス化とアンボックス化

`object`はすべての型の基底となる型．

値型を`object`として扱う場合はボックス化される．

```csharp
int temperature = 72;

object boxedTemperature = temperature;
```

逆に，`object`から元の値型へ戻す場合はアンボックス化する．

```csharp
int unboxedTemperature = (int)boxedTemperature;
```

また，structなどの値型をinterface型として扱う場合にもボックス化が発生する．

```csharp
Packet packet = new(7);
ILabelled labelledPacket = packet;
```

### ParseとTryParse

`Parse`を使うと，文字列を数値などの型へ変換できる．

```csharp
string textValue = "512";
int parsed = int.Parse(textValue);
```

ただし，変換できない文字列の場合は例外が発生する．

`TryParse`では変換できるかを試し，成功した場合は`true`と変換結果を返す．
失敗しても例外は発生せず，`false`になる．

```csharp
string userInput = "12x";

bool parsedSuccessfully =
    int.TryParse(userInput, out int safeValue);
```

前に学習した`Enum.TryParse`と同じような使い方だった．

### タプル

タプルを使うと，複数の値を1つにまとめて扱うことができる．

```csharp
(string Name, int Age) person = ("Alice", 30);
```

要素名を指定しなかった場合は，

```csharp
(string, int) unnamed = ("Bob", 25);
```

のように`Item1`，`Item2`でアクセスできる．

```csharp
Console.WriteLine(unnamed.Item1);
```

`var`を使って要素名を付けることもできる．

```csharp
var city = (Name: "Seattle", Population: 749_256);
```

### タプルの分解

タプルはデコンストラクションによって複数の変数へ分解できる．

```csharp
var point = (X: 3, Y: 7);

var (x, y) = point;
```

型を明示したり，既存の変数へ分解することもできる．

```csharp
(int px, int py) = point;

int a, b;
(a, b) = point;
```

`foreach`でもタプルをそのまま分解できる．

```csharp
foreach (var (name, score) in results)
{
    Console.WriteLine($"{name}: {score}");
}
```

不要な要素は`_`で破棄できる．

```csharp
var (_, max, _) = ComputeStats(values);
```

### タプルをメソッドの戻り値に使う

タプルを使うことで，メソッドから複数の値をまとめて返すことができる．

```csharp
static (double Minimum, double Maximum, double Average)
    ComputeStats(List<double> values)
{
    var min = values.Min();
    var max = values.Max();
    var avg = values.Average();

    return (min, max, avg);
}
```

呼び出し側ではそのまま分解できる．

```csharp
var (min, max, avg) = ComputeStats(data);
```

### タプルとDictionary

Dictionaryの値としてタプルを使うことができる．

```csharp
var sizeChart = new Dictionary<string, (int Min, int Max)>
{
    ["Small"] = (0, 50),
    ["Medium"] = (51, 100),
    ["Large"] = (101, 200)
};
```

これによって，1つのキーに複数の関連する値をまとめて持たせることができる．

また，Dictionaryのキーとしてタプルを使うこともできる．

```csharp
var grid = new Dictionary<(int Row, int Column), string>
{
    [(0, 0)] = "Origin",
    [(1, 3)] = "Sensor A",
    [(2, 5)] = "Sensor B"
};
```

座標のように複数の値を組み合わせてキーにできるので便利そうだと感じた．

### タプルの等値性

タプルは要素の値と位置によって比較できる．

```csharp
var order1 = (Product: "Widget", Quantity: 5);
var order2 = (Product: "Widget", Quantity: 5);

Console.WriteLine(order1 == order2);
```

要素名が違っていても，値と位置が同じであれば等しいと比較される．

```csharp
var named = (X: 1, Y: 2);
var different = (A: 1, B: 2);

Console.WriteLine(named == different);
```

### with式によるタプルのコピー

タプルでも`with`式を使うことで，一部の値だけを変更したコピーを作成できる．

```csharp
var original = (Name: "Widget", Price: 19.99m, InStock: true);

var discounted = original with
{
    Price = 14.99m
};
```

元の`original`には影響しない．

### デリゲートとラムダ式

デリゲートは，メソッドや処理そのものを変数のように扱うための仕組み．

```csharp
delegate int Transform(int value);

Transform doubler = x => x * 2;
Transform squarer = Square;
```

ラムダ式をそのままデリゲートへ入れることも，既存のメソッドを入れることもできる．

ラムダ式は，

```csharp
x => x * 2
```

のように`=>`を使って簡単な処理を書くことができる．

### FuncとAction

.NETには組み込みのデリゲート型として`Func`と`Action`がある．

```csharp
Func<int, int, int> add =
    (left, right) => left + right;
```

`Func<int, int, int>`では，最初の2つの`int`が引数で，最後の`int`が戻り値となる．

```csharp
Action<string> report =
    message => Console.WriteLine($"Report: {message}");
```

`Action`は戻り値を持たない処理を表す．

```text
Func
→ 戻り値あり

Action
→ 戻り値なし
```

### ラムダ式をメソッドに渡す

ラムダ式は処理そのものとしてメソッドへ渡すことができる．

```csharp
int[] evenNumbers =
    Filter(numbers, value => value % 2 == 0).ToArray();
```

この場合，

```csharp
value => value % 2 == 0
```

という「偶数ならtrueを返す処理」を`Filter`へ渡している．

### staticラムダ

ラムダ式に`static`を付けると，ラムダ式の外側にあるローカル変数などを参照できなくなる．

```csharp
Func<int, bool> isEven =
    static value => value % 2 == 0;
```

外側の状態に依存せず，渡された値だけを使って処理するラムダにできる．

### 破棄パラメーター

ラムダ式の引数として受け取る必要はあるが，処理で使わない値は`_`で破棄できる．

```csharp
Action<int, int, string> statusUpdate =
    (_, _, message) => Console.WriteLine(message);
```

この場合，最初の2つの`int`は使わず，`message`だけを使用する．

### イベント

イベントを使うと，何かが発生したときに登録しておいた処理を実行できる．

```csharp
publisher.MessagePublished +=
    (_, message) => Console.WriteLine($"Received: {message}");
```

`+=`でイベント発生時に実行する処理を登録する．

その後，

```csharp
publisher.Publish("Records updated");
```

によってイベントが発生すると，登録していたラムダ式が実行される．
