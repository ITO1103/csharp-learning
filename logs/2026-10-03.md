## 学んだこと

### リレーショナル・論理パターン

`<`，`>`，`<=`，`>=`を使って値を定数と比較できる．また，`and`，`or`，`not`を使って複数のパターンを組み合わせることができる．

```csharp
temperature switch
{
    < 0 => "Below freezing",
    >= 18 and <= 24 => "Comfortable",
    (>= 0 and < 10) or > 30 => "Far outside the comfortable range",
    _ => "Cool or warm"
};
```

括弧を使うことでパターンをグループ化できる．

```csharp
// 1以上3以下，または9の場合にtrue
priority is (>= 1 and <= 3) or 9;
```

また，パターンだけでは表現しにくい追加条件は`when`ガードを使って指定できる．

```csharp
> 35 when isOutdoors => "High heat outdoors"
```

### リスト・スライスパターン

リストパターンでは，要素数，値，並び順をまとめてパターンとして判定できる．

```csharp
static bool IsHeader(string[] columns) =>
    columns is ["Name", "Score"];
```

`_`を使うとその位置の1要素を無視できる．

```csharp
[var winner, _, var thirdPlace]
```

一方，`..`は0個以上の要素に一致するため，要素数が決まっていない部分を許可できる．

```csharp
["--verbose", .., var fileName]
```

また，スライスした部分にさらにパターンを適用することもできる．

```csharp
entries is ["BEGIN", .. { Length: > 0 }, "END"];
```

この場合，`BEGIN`と`END`の間に1個以上の要素がある場合に一致する．

### 破棄

`_`を使うことで，必要のない値を明示的に無視できる．

`switch`式では，それまでのどのパターンにも一致しなかった値を処理できる．

```csharp
string message = statusCode switch
{
    200 => "Ready",
    404 => "Not found",
    _ => "Another status"
};
```

タプルの脱構築では，不要な要素を受け取らずに破棄できる．

```csharp
// CityとHighだけ取得しLowとRainChanceは_で無視
var (city, high, _, _) = GetForecast();
```

`out _`を使うと，メソッドの成功・失敗だけを利用し，`out`で返される値を無視できる．

```csharp
static bool IsWholeNumber(string text) =>
    int.TryParse(text, out _);
```

ラムダ式でも，使わないパラメーターを`_`として記述できる．

```csharp
EventHandler handler = (_, _) => Console.WriteLine("Timer tick");
```

同じ`_`でも使用する場所によって役割は異なるが，必要のない値を明示するという点は共通している．

## 詰まったこと・分からなかったこと・知らなかったこと

- リレーショナルパターンでは比較対象に定数を使用すること
- `and`，`or`，`not`でパターン同士を組み合わせられること
- `when`ガードを使うことでパターン以外の追加条件を指定できること
- リストパターンでは要素数も一致する必要があること
- リストパターンの`_`はその位置の1要素だけを無視すること
- スライスパターンの`..`は0個以上の要素に一致すること
- `..`で一致した部分にさらにパターンを適用できること
- `_`は`switch`，脱構築，`out`，ラムダ式など複数の場所で不要な値を示すために使えること
