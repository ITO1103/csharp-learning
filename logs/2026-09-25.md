## 学んだこと

### 匿名型

匿名型を使うと，classなどの型を定義せずに一時的なオブジェクトを作ることができる．

```csharp
var person = new
{
    Name = "Alice",
    Age = 30
};
```

匿名型は型名を直接書くことができないため，`var`で受け取る．

```csharp
var person = new { Name = "Alice", Age = 30 };
```

### 推論されたプロパティ名

既存の変数を匿名型にそのまま入れると，変数名からプロパティ名を推論してくれる．

```csharp
string productName = "Laptop";
decimal price = 999.99m;

var product = new
{
    productName,
    price
};
```

この場合は，

```csharp
product.productName
product.price
```

のようにアクセスできる．

また，

```csharp
Console.WriteLine($"{product.price:C}");
```

の`:C`は通貨形式で表示するための書式指定子．

### 匿名型の等値性

同じプロパティと値を持つ匿名型は，値で比較できる．

```csharp
var a = new { Name = "Alice", Age = 30 };
var b = new { Name = "Alice", Age = 30 };
var c = new { Name = "Bob", Age = 25 };

Console.WriteLine(a.Equals(b));
Console.WriteLine(a.Equals(c));
```

`a`と`b`は同じ値を持つので`true`になり，`a`と`c`は値が違うので`false`になる．

### LINQで匿名型を使用する

LINQは，配列やListなどのデータを絞り込み，変換，並び替えするための機能．

匿名型はLINQで必要な項目だけを取り出して，新しい形にまとめる場合に使える．

```csharp
var words = new[]
{
    "apple",
    "blueberry",
    "cherry"
};

var results =
    words.Select(w => new
    {
        Word = w,
        Length = w.Length
    });
```

この場合は，各文字列から文字列そのものと文字数を取り出し，匿名型としてまとめている．

### 入れ子になった匿名型

匿名型の中にさらに匿名型を入れることもできる．

```csharp
var order = new
{
    OrderId = 1,
    Customer = new
    {
        Name = "Alice",
        City = "Seattle"
    },
    Total = 150.00m
};
```

入れ子になった値には，

```csharp
order.Customer.Name
order.Customer.City
```

のようにアクセスできる．

### null許容値型

`int`や`double`，`bool`などの値型は通常`null`を持てないが，`?`を付けることで`null`を持てるようになる．

```csharp
int? age = null;
double? price = 9.99;
bool? isActive = null;
```

後から通常の値を代入することもできる．

```csharp
age = 30;
```

配列の各要素をnull許容値型にすることもできる．

```csharp
int?[] scores =
[
    100,
    null,
    85,
    null,
    72
];
```

### 値が存在するか確認する

`is`を使うことで，nullではないことを確認しながら値を取り出せる．

```csharp
int? temperature = 72;

if (temperature is int degrees)
{
    Console.WriteLine($"Temperature is {degrees}°F.");
}
```

この場合，`temperature`がnullではなければ，値を`degrees`として取り出す．

`HasValue`を使って値が存在するか確認することもできる．

```csharp
int? count = 42;

if (count.HasValue)
{
    Console.WriteLine($"Count is {count.Value}.");
}
```

`HasValue`は値が存在する場合に`true`になり，`Value`で実際の値を取得できる．

nullと直接比較することもできる．

```csharp
int? quantity = null;

if (quantity != null)
{
    Console.WriteLine($"Quantity: {quantity.Value}");
}
```

### フォールバックを使用して値を取得する

`GetValueOrDefault()`を使うと，値が存在すればその値を取得し，nullの場合はデフォルト値を取得できる．

```csharp
int? rating = null;

int result1 = rating.GetValueOrDefault();
```

`int`の場合はデフォルト値として`0`が返る．

フォールバック値を自分で指定することもできる．

```csharp
int result2 = rating.GetValueOrDefault(-1);
```

この場合，`rating`がnullなら`-1`になる．

`??`を使って同じようにフォールバック値を指定することもできる．

```csharp
int? priority = null;

int effective = priority ?? 0;
```

`priority`がnullの場合は`0`を使用し，値が存在する場合はその値を使用する．

### null許容値型の算術演算

null許容値型でも通常の算術演算を行うことができる．

```csharp
int? a = 10;
int? b = 20;
int? c = null;

int? sum = a + b;
int? product = a * c;
```

`a + b`は両方に値が入っているため`30`になる．

一方で，`a * c`は`c`がnullなので，結果もnullになる．

```csharp
Console.WriteLine(product.HasValue);
```

この場合は`false`になる．

null許容値型の算術演算では，どちらかの値がnullの場合は計算結果もnullになる．

## 詰まったこと・分からなかったこと・知らなかったこと

- 匿名型では型名を直接書けないこと
- 匿名型のプロパティ名を変数名から推論できること
- 文字列補間の`:C`が通貨形式を表していること
- LINQが何をするための機能なのか
- 匿名型をLINQの結果として使えること
- 匿名型の中にさらに匿名型を入れられること
- 値型でも`?`を付けることでnullを扱えること
- `is int degrees`でnullチェックと値の取り出しを同時にできること
- `HasValue`と`Value`の使い方
- `GetValueOrDefault()`と`??`の違い
- null許容値型の計算ではnullが結果に伝わること
