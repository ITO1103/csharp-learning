## 学んだこと

### インターフェース

interfaceは，実装する型に「このメンバーを必ず用意する」という契約を持たせるもの．

```csharp
interface ILogger
{
    void Log(string message);
    string Name { get; }
}
```

このinterfaceを実装する場合，

```csharp
public class ConsoleLogger : ILogger
{
    public string Name => "Console";

    public void Log(string message)
        => Console.WriteLine($"[{Name}] {message}");
}
```

のように，`ILogger`で宣言された`Name`プロパティと`Log`メソッドを実装する必要がある．

interface名の先頭には`I`を付けるのが一般的な命名規則．

また，1つのclassで複数のinterfaceを実装することもできる．

```csharp
public class Runway(double meters) : IMetric, IImperial
```

複数のinterfaceに同じ名前のメソッドが存在する場合は，

```csharp
double IMetric.GetDistance() => meters;
double IImperial.GetDistance() => meters * 3.28084;
```

のように明示的に実装することで，どのinterfaceのメソッドかを分けることができる．

interface自体も別のinterfaceを継承できる．

```csharp
interface IDrawable
{
    void Draw();
}

interface IShape : IDrawable
{
    double Area { get; }
}
```

この場合，`IShape`を実装するclassは`Area`だけでなく，`IDrawable`から継承した`Draw()`も実装する必要がある．

`internal interface`を使うと，interfaceそのものを同じアセンブリ内だけに隠すことができる．

```csharp
internal interface ILoggable
{
    void Log(string message);
}
```

publicなclassがinternalなinterfaceを実装していても，公開してよいメソッドはpublicとして外部から利用できる．

一方で，internalな型を引数に使用するメソッドなどは，明示的interface実装にすることでpublic APIとして外部に公開しないようにできる．

### 列挙型

enumは，決まった選択肢に名前を付けて扱う型．

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

値を指定しない場合，内部的には`0`から順番に整数値が割り当てられる．

```text
Spring = 0
Summer = 1
Autumn = 2
Winter = 3
```

enumの基になる型は既定では`int`だが，

```csharp
enum HttpStatus : ushort
{
    OK = 200,
    NotFound = 404,
    InternalServerError = 500
}
```

のように，`ushort`など別の整数型を指定できる．

enumはswitch式でも使用できる．

```csharp
static string DescribeSeason(Season season) => season switch
{
    Season.Spring => "Flowers bloom and temperatures rise.",
    Season.Summer => "Long days and warm weather.",
    Season.Autumn => "Leaves change color and fall.",
    Season.Winter => "Short days and cold temperatures.",
    _ => throw new ArgumentOutOfRangeException(nameof(season))
};
```

`[Flags]`属性を付けると，複数のenum値をビット単位で組み合わせて扱うことができる．

```csharp
[Flags]
enum FileAccess
{
    None = 0,
    Read = 1,
    Write = 2,
    Execute = 4,
    ReadWrite = Read | Write,
    All = Read | Write | Execute
}
```

単独のフラグは，ビットが重ならないように`1, 2, 4, 8...`のような2の累乗で定義する．

```csharp
var permissions = FileAccess.Read | FileAccess.Write;
```

とすると，ReadとWriteの両方を持つ状態を表せる．

enumと基になる整数型は相互にキャストできる．

```csharp
var status = HttpStatus.NotFound;
ushort code = (ushort)status;

var fromCode = (HttpStatus)200;
```

また，

```csharp
Enum.Parse<Season>("Winter");
```

で文字列をenum値に変換できる．

`TryParse`を使用すると，変換できるか試し，成功した場合に結果を`out`引数へ入れることができる．

```csharp
if (Enum.TryParse<Season>("Winter", out var season))
{
    Console.WriteLine(season);
}
```

`Enum.GetValues<Season>()`を使うと，enumに定義されている値をすべて取得できる．

### ジェネリック

ジェネリックを使用すると，型を固定せず，後から具体的な型を指定して同じコードを使い回すことができる．

ジェネリックメソッドでは，

```csharp
static void Print<T>(T value)
    => Console.WriteLine($"Value: {value}");
```

のように`T`を使用する．

```csharp
Print(42);
Print("Hello");
Print(3.14);
```

とすると，それぞれ`int`，`string`，`double`として型が推論される．

### ジェネリックコレクション

`List<T>`，`Dictionary<TKey, TValue>`，`HashSet<T>`，`Queue<T>`など，型を指定して利用するコレクションがある．

```csharp
List<string> names = ["Alice", "Bob", "Carol"];
```

```csharp
Dictionary<string, int> inventory = new()
{
    ["Apples"] = 50,
    ["Oranges"] = 30
};
```

```csharp
HashSet<int> uniqueIds = [1, 2, 3, 1, 2];
```

```csharp
Queue<string> tasks = new();
```

それぞれ用途が異なり，Listは順番を持つ一覧，Dictionaryはキーと値，HashSetは重複しない集合，QueueはFIFOとして扱う．

### コレクション式

`[]`を使って，配列やListなどを簡潔に初期化できる．

```csharp
List<string> fruits = ["Apple", "Banana", "Cherry"];
int[] numbers = [1, 2, 3, 4, 5];
```

また，`..`を使うことで既存のコレクションの要素を展開できる．

```csharp
List<int> first = [1, 2, 3];
List<int> second = [4, 5, 6];

List<int> combined = [.. first, .. second];
```

### Dictionaryの上書き

Dictionaryをコピーしたあと，別のDictionaryの値を代入することで設定を上書きできる．

```csharp
Dictionary<string, int> config = new(defaults);

foreach (var (key, value) in overrides)
{
    config[key] = value;
}
```

同じキーが存在する場合は値が上書きされ，存在しない場合は新しく追加される．

### 型制約

ジェネリックの`T`は型を固定しないが，

```csharp
where T : ...
```

を使うことで，使用できる型に条件を付けることができる．

```csharp
static T Max<T>(T a, T b)
    where T : IComparable<T>
    => a.CompareTo(b) >= 0 ? a : b;
```

`where T : IComparable<T>`では，`T`を比較可能な型に限定している．

```csharp
static T CreateDefault<T>()
    where T : new()
    => new T();
```

`where T : new()`では，引数なしコンストラクタを持つ型だけに限定している．

型制約は，ジェネリックで型そのものは固定しないまま，どの型を使用できるかを制限するためのもの．

### 共変性と反変性

ジェネリック型でも，型の継承関係を利用できる場合がある．

```csharp
List<Dog> dogs = [new("Rex"), new("Buddy")];
IEnumerable<Animal> animals = dogs;
```

`Dog`は`Animal`の一種なので，`IEnumerable<Dog>`を`IEnumerable<Animal>`として扱える．
これが共変性．

一方，

```csharp
Action<Animal> printAnimal =
    a => Console.WriteLine($"Animal: {a.Name}");

Action<Dog> printDog = printAnimal;
```

のように，`Animal`を受け取れる処理を`Dog`用として扱うこともできる．
これが反変性．

### 独自のジェネリック型

ジェネリックメソッドだけでなく，自分でジェネリックなclassを作ることもできる．

```csharp
public class GenericList<T>
{
}
```

と定義すると，

```csharp
new GenericList<int>();
new GenericList<string>();
```

のように，格納する型を後から指定できる．

今回の例では，Nodeをつなげる形で独自のリストを作成した．

```text
head
 ↓
Node → Node → Node → null
```

`AddHead()`で先頭にNodeを追加し，`GetEnumerator()`と`yield return`を使うことで`foreach`でも要素を取り出せるようにした．
