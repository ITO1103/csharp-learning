## 学んだこと

### 文字列の連結

文字列は`+`や`+=`を使って連結できる．

```csharp
string name = "Alex";
string day = "Monday";

string greeting =
    "Hello " + name + ". Today is " + day + ".";

greeting += " How are you today?";
```

文字列補間を使うと，`+`で連結するより読みやすく書くことができる．

```csharp
string greeting =
    $"Hello {name}. Today is {day}.";
```

複数の文字列をまとめて連結する場合は，`Concat`や`Join`も使用できる．

```csharp
string[] words = ["The", "quick", "brown", "fox"];

string runTogether = string.Concat(words);
string sentence = string.Join(' ', words);
```

`Concat`はそのまま連結し，`Join`は指定した区切り文字を間に入れて連結する．

また，ループ内で何度も文字列を追加する場合は`StringBuilder`を使用できる．

```csharp
var builder = new StringBuilder();

for (int i = 1; i <= 3; i++)
{
    builder.AppendLine($"Line {i}");
}
```

### 文字列補間

`$`を付けることで，文字列の中に変数や式を埋め込むことができる．

```csharp
string name = "Alex";

Console.WriteLine($"Hello {name}");
```

`:`の後ろに書式を指定することもできる．

```csharp
var date = new DateTime(1731, 11, 25);

Console.WriteLine(
    $"{date:dddd, MMMM dd, yyyy}"
);
```

フィールドの幅と配置も指定できる．

```csharp
Console.WriteLine(
    $"|{"Author",-25}|{"Title",30}|"
);
```

正の値では右揃え，負の値では左揃えになる．
配置と書式を同時に設定する場合は，

```csharp
$"{value,7:F3}"
```

のように書く．

補間式の中で三項演算子を使用する場合は，式を`()`で囲む．

```csharp
Console.WriteLine(
    $"Coin flip: {(rand.NextDouble() < 0.5 ? "heads" : "tails")}"
);
```

また，`{{`と`}}`を使うことで中かっこ自体を表示できる．

```csharp
Console.WriteLine(
    $"{{{string.Join(", ", xs)}}}"
);
```

`CultureInfo`を使うことで，国や地域ごとの形式で日時や数値を表示できることも知った．

### nameof演算子

`nameof`を使うと，型，変数，プロパティなどの名前を文字列として取得できる．

```csharp
Console.WriteLine(nameof(Customer));
Console.WriteLine(nameof(Customer.Name));

var customer = new Customer("Ada");

Console.WriteLine(nameof(customer));
Console.WriteLine(nameof(customer.Name));
```

値を取得するのではなく，名前そのものを取得する．

```csharp
nameof(customer.Name)
```

の場合は`"Name"`になる．

修飾された名前でも，最後の識別子だけが返される．

```csharp
nameof(System.Collections.Generic.List<int>)
```

の場合は`"List"`になる．

### nameofを引数の検証に使用する

例外を投げる際の引数名として`nameof`を使用できる．

```csharp
if (string.IsNullOrWhiteSpace(name))
{
    throw new ArgumentException(
        "Name must be non-empty.",
        nameof(name)
    );
}
```

`"name"`と文字列を直接書くよりも，変数名を変更した場合に修正漏れが起きにくい．

nullチェックの場合は，

```csharp
ArgumentNullException.ThrowIfNull(customer);
```

のように，引数名を自動で取得する方法もある．

### プロパティ変更通知

`INotifyPropertyChanged`を使うことで，プロパティが変更されたことをイベントとして通知できる．

```csharp
person.PropertyChanged += (_, e) =>
    Console.WriteLine($"changed: {e.PropertyName}");
```

`(_, e)`では，1つ目の引数は使用しないので`_`で破棄し，2つ目の引数を`e`という変数で受け取っている．

```csharp
OnPropertyChanged(nameof(Name));
```

のように`nameof`を使うことで，プロパティ名を文字列として直接書かずに変更通知へ渡せる．

また，`[CallerMemberName]`を使うと，呼び出し元のメンバー名を自動的に取得できる．

### 属性とnameof

属性は，クラスやメソッド，引数などに追加情報を付けるための仕組み．

```csharp
[Obsolete]
[NotNullWhen(true)]
[CallerMemberName]
```

など，これまで学習したものにも属性が使われていた．

属性によって，コンパイラに追加の情報を与えたり，フレームワークに特別な処理をさせたりできる．

属性の引数にも`nameof`を使用できる．

```csharp
[return: NotNullIfNotNull(nameof(input))]
static string? NormalizeOrNull(string? input) =>
    input?.Trim();
```

文字列で名前を直接指定するよりも，名前を変更したときに修正漏れしにくくなる．

## 詰まったこと・分からなかったこと・知らなかったこと

- `nameof`は値ではなく識別子の名前を文字列として返すこと
- `nameof`で使用する型は実際に定義されている必要があること
- `ArgumentNullException.ThrowIfNull`では引数名も自動的に取得されること
- `INotifyPropertyChanged`と`PropertyChanged`イベントの仕組み
- イベントハンドラーの`(_, e)`が何を表しているのか
- 属性が何のために使われるものなのか
- 属性の引数にも`nameof`を使用できること
- 文字列補間で配置やカルチャを指定できること

## 解決方法

- Microsoft Learnのコードを実際に動かして確認した
- 分からないところはその都度調べた
- サンプルだけでは動かないコードには必要なクラスやメソッドを追加した
- コードにコメントを付けながら挙動を確認した

## 振り返り

文字列の連結や補間については以前から使用していたが，`Join`や配置，カルチャの指定など，知らなかった書き方も多かった．

`nameof`については，単純に名前を文字列として取得するだけでなく，引数の検証やプロパティ変更通知，属性などで使用できることを知った．
特に，文字列として名前を直接書くよりも，リファクタリング時の修正漏れを防げる点が便利だと感じた．

また，これまで何度か出てきた属性について，コンパイラやフレームワークに追加情報を渡すためのものだと改めて理解した．
