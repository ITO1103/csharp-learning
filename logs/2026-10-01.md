## 学んだこと

### 文字列を分割する

`Split`を使うことで，指定した区切り文字ごとに文字列を分割し，配列として取得できる．

```csharp
string phrase = "The quick brown fox jumps over the lazy dog.";
string[] words = phrase.Split(' ');
```

複数の区切り文字を使用する場合は，`char`の配列を渡すことができる．

```csharp
char[] delimiters = [' ', ',', '.', ':', '\t'];

string[] words = text.Split(delimiters);
```

区切り文字が連続している場合は，空文字列の要素が生成されることがある．

複数文字からなる区切り記号を使う場合は，`string`の配列を指定できる．

```csharp
string[] separators = ["<<", "..."];

string[] words =
    text.Split(
        separators,
        StringSplitOptions.RemoveEmptyEntries
    );
```

`StringSplitOptions.RemoveEmptyEntries`を指定すると，分割結果から空の要素を除外できる．

また，返される要素数の上限を指定することもできる．

```csharp
string[] words =
    phrase.Split(
        ' ',
        4,
        StringSplitOptions.None
    );
```

この場合は最大4個の要素に分割され，4個目に残りの文字列が入る．

`StringSplitOptions.TrimEntries`を使うと，分割された各要素の先頭と末尾の空白を削除できる．

```csharp
string[] trimmed =
    numerals.Split(
        ',',
        StringSplitOptions.TrimEntries
    );
```

### 文字列補間の復習

文字列補間では，`$`を付けることで文字列の中に変数や式を埋め込める．

```csharp
Console.WriteLine(
    $"Hello, {name}! You have {itemCount} items in your cart."
);
```

`:`の後ろに書式を指定できる．

```csharp
Console.WriteLine($"Subtotal: {subtotal:C}");
Console.WriteLine($"Tax rate: {taxRate:P0}");
```

また，`,`の後ろに数値を指定することで表示幅と配置を指定できる．

```csharp
Console.WriteLine(
    $"{order.Name,-12}" +
    $"{order.Quantity,3}" +
    $"{order.Price * order.Quantity,10:C}"
);
```

負の値では左揃え，正の値では右揃えになる．

`string.Create`と`CultureInfo`を使うことで，カルチャを指定して文字列を生成できる．

```csharp
string germanReceipt =
    string.Create(
        new CultureInfo("de-DE"),
        $"Gesamt: {total:C}"
    );
```

`CultureInfo.InvariantCulture`を使うと，実行環境に依存しない形式で出力できる．

### パターンマッチング

パターンマッチングでは，値の型，値，プロパティなどを条件として処理を分けることができる．

`is`を使うことで，指定した型かどうかを確認し，一致した場合はその型の変数として使用できる．

```csharp
if (delivery is ExpressDelivery express)
{
    Console.WriteLine(
        $"Track express package {express.TrackingCode}"
    );
}
```

この場合，`delivery`が`ExpressDelivery`型の場合に`express`として使用できる．

`is null`を使ってnullチェックすることもできる．

```csharp
if (delivery is null)
{
    Console.WriteLine("No package is available.");
}
```

`switch`文では，型ごとに処理を分岐できる．

```csharp
switch (delivery)
{
    case null:
        Console.WriteLine("No delivery was scheduled.");
        break;

    case ExpressDelivery express:
        Console.WriteLine(
            $"Express delivery {express.TrackingCode} is ready."
        );
        break;

    case StandardDelivery standard:
        Console.WriteLine(
            $"Standard delivery arrives in {standard.Days} days."
        );
        break;
}
```

`switch`式では，一致したパターンに応じた値を返すことができる．

```csharp
static string GetStatusMessage(StandardDelivery delivery) =>
    delivery.Days switch
    {
        0 => "Delivered today",
        1 => "Arriving tomorrow",
        <= 3 => "Arriving soon",
        _ => "In transit"
    };
```

型だけでなく，プロパティの値も条件として指定できる．

```csharp
StandardDelivery { Days: <= 2 }
    => "Standard delivery arriving soon"
```

`_`は，それまでのどのパターンにも一致しなかった場合を表す．

## 詰まったこと・分からなかったこと・知らなかったこと

- `Split`で区切り文字が連続した場合に空の要素が生成されること
- `RemoveEmptyEntries`で空の要素を除外できること
- `Split`の要素数指定は分割回数ではなく，返される要素数の上限であること
- `TrimEntries`で分割後の各要素の前後の空白を削除できること
- `is`で型を判定すると同時に，その型の変数として値を取得できること
- `switch`文と`switch`式で型や値に応じたパターンマッチングができること
- プロパティの値まで条件に含めたパターンを記述できること
