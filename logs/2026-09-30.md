## 学んだこと

### 文字列の内容を変更する

`Replace`を使うことで，指定した文字列や文字を別のものに置き換えることができる．

```csharp
string source = "The mountains are behind the clouds today.";

string updated =
    source.Replace("mountains", "peaks");
```

`string`は不変なので，元の文字列自体が変更されるのではなく，新しい文字列が作成される．

`Trim`，`TrimStart`，`TrimEnd`を使うことで，文字列の前後にある空白を削除できる．

```csharp
source.Trim();
source.TrimStart();
source.TrimEnd();
```

`IndexOf`で削除したい文字列の位置を取得し，`Remove`でその位置から指定した文字数を削除できる．

```csharp
int index = source.IndexOf(toRemove);

string result = index >= 0
    ? source.Remove(index, toRemove.Length)
    : source;
```

`IndexOf`は文字列が見つかった場合は開始位置を返し，見つからない場合は`-1`を返す．

正規表現を使用すると，特定のパターンに一致する文字列を置き換えることもできる．

```csharp
string result = Regex.Replace(
    source,
    """the\s""",
    match => char.IsUpper(match.Value[0])
        ? "Many "
        : "many ",
    RegexOptions.IgnoreCase);
```

また，`string`は不変なので個々の文字を直接書き換えることはできないが，`Span<char>`にコピーすることで文字単位の変更ができる．

```csharp
Span<char> characters =
    stackalloc char[phrase.Length];

phrase.CopyTo(characters);
```

### 文字列の比較

`Equals`や`==`を使うことで，2つの文字列が等しいか比較できる．

```csharp
Console.WriteLine(root.Equals(root2));
Console.WriteLine(root == root2);
```

デフォルトでは大文字小文字を区別して比較する．

`StringComparison.OrdinalIgnoreCase`を指定すると，大文字小文字を無視できる．

```csharp
bool equalIgnoringCase =
    string.Equals(
        root,
        root2,
        StringComparison.OrdinalIgnoreCase
    );
```

`Compare`を使うと，2つの文字列の並び順を比較できる．

```csharp
int order =
    string.Compare(
        first,
        second,
        StringComparison.Ordinal
    );
```

戻り値は，

- 負の数の場合は1つ目の文字列が前
- `0`の場合は同じ
- 正の数の場合は1つ目の文字列が後

となる．

文字列定数との比較では，`is`や`switch`を使うこともできる．

```csharp
if (status is "Ready")
{
    Console.WriteLine("The system is ready.");
}
```

```csharp
string instruction = heading switch
{
    "North" => "Travel due North for 10 km.",
    "South" => "Travel due South for 10 km.",
    _ => $"Unknown heading: {heading}.",
};
```

### 文字列の検索

`Contains`を使うことで，文字列の中に指定した文字列が含まれているか確認できる．

```csharp
bool result =
    factMessage.Contains("extension");
```

`StartsWith`では指定した文字列から始まっているか，`EndsWith`では指定した文字列で終わっているかを確認できる．

```csharp
factMessage.StartsWith(
    "extension",
    StringComparison.CurrentCultureIgnoreCase
);

factMessage.EndsWith(
    ".",
    StringComparison.Ordinal
);
```

1文字だけを検索する場合は，`char`をそのまま指定することもできる．

```csharp
bool hasSlash = path.Contains('/');
```

`IndexOf`は最初に一致する位置を，`LastIndexOf`は最後に一致する位置を返す．

```csharp
int first =
    factMessage.IndexOf("methods")
    + "methods".Length;

int last =
    factMessage.LastIndexOf("methods");
```

`Substring`を使うことで，指定した位置から文字列の一部を取り出すことができる．

```csharp
string between =
    factMessage.Substring(
        first,
        last - first
    );
```

## 詰まったこと・分からなかったこと・知らなかったこと

- `IndexOf`が文字列の開始位置を返し，見つからない場合は`-1`を返すこと
- `Remove`の第1引数が開始位置，第2引数が削除する文字数であること
- `Regex.Replace`で正規表現に一致した文字列ごとにラムダ式を使って置換内容を決められること
- `string`は不変なので，文字単位で変更する場合は`Span<char>`など別の領域にコピーする必要があること
- `Compare`は`true`や`false`ではなく，負の数，`0`，正の数を返すこと
- `StringComparison.OrdinalIgnoreCase`を使うと大文字小文字を無視して比較できること
- `IndexOf`と`LastIndexOf`を組み合わせることで，2つの文字列の間を取り出せること
